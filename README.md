# Kamirty Motion · مولّد الإنفوجرافيك

**الموقع:** https://motion.kamirtyai.com

أداة مجانية تعمل بالكامل داخل المتصفح، تحوّل وصفًا عربيًا مكتوبًا إلى فيديو إنفوجرافيك متحرك مدته **دقيقتان بالضبط**. لا تحتاج إلى حساب أو خادم أو أي خدمة مدفوعة، ولا تُرفع نصوص الزوار أو ملفاتهم إلى أي مكان.

## ماذا تقدم للزائر
- **وصف ← فيديو:** محلل عربي يحوّل الجمل إلى مشاهد مناسبة:
  - الأرقام والنسب تصبح عدّادات وحلقات متحركة.
  - القوائم المرقّمة تصبح خطوات، و«الاسم: 40%» يصبح أعمدة بيانية، و«2020: حدث» يصبح خطًا زمنيًا.
  - جملة فيها «بينما» أو «مقابل» تصبح مقارنة، والسؤال المتبوع بجوابه يصبح مشهد سؤال وجواب، والنص بين علامتي تنصيص يصبح اقتباسًا.
  - المحلل لا يخترع معلومات من عنده.
- **8 أنواع مشاهد:** افتتاحية، رقم وعدّاد، خطوات، مقارنة، خط زمني، اقتباس، بطاقات، خاتمة.
- **3 مقاسات:** أفقي 16:9، وعمودي 9:16 للريلز وتيك توك، ومربع 1:1.
- **التصميم:**
  - 8 قوالب لونية، ويمكن تخصيص ألوان الهوية.
  - 8 خطوط عربية مستضافة محليًا.
  - أرقام هندية (١٢٣) أو عربية (123).
  - 4 انتقالات بين المشاهد، و4 خلفيات متحركة.
  - أكثر من 160 أيقونة تُختار تلقائيًا من الكلمات العربية.
- **التحرير:**
  - تعديل أي مشهد: النوع، والنصوص، والأيقونة، والمدة. مجموع الفيديو يبقى 120 ثانية دائمًا.
  - ترتيب المشاهد ونسخها وحذفها وإضافتها.
  - تراجع وإعادة، وحفظ تلقائي في المتصفح، وحفظ وفتح المشروع كملف JSON.
- **الصوت:** ثلاث مقطوعات موسيقية تُولَّد داخل المتصفح بلا حقوق نشر، أو ملف صوتي يرفعه الزائر من جهازه.
- **التصدير:**
  - MP4 (H.264) إن دعمه المتصفح، وإلا WebM.
  - بجودة 720p أو 1080p.
  - مع شريط تقدّم وزر إلغاء، وتحقق من الملف الناتج: المدة، وعدد الإطارات، والأبعاد.

## التطوير
```bash
npm ci
npm run dev        # خادم التطوير
npm run typecheck  # فحص الأنواع
npm test           # الاختبارات
npm run build      # بناء الملفات الثابتة في dist/
```

## النشر
- كل دمج في `main` يشغّل `.github/workflows/deploy.yml`: يجري الفحص والاختبارات والبناء، ثم ينشر `dist/` إلى الفرع `gh-pages`.
- GitHub Pages يخدم الفرع `gh-pages` على النطاق `motion.kamirtyai.com`.
- إعداد DNS في Squarespace: سجل `CNAME` باسم `motion` يشير إلى `kamirty.github.io`.

## البنية
```
src/domain/           الأنواع، والتوقيت (3600 إطار)، وتنقية المشاريع المستوردة
src/design/           القوالب اللونية، والخطوط، والأرقام، والأيقونات
src/engine/parser/    تحليل الوصف العربي إلى مخطط مشاهد
src/engine/planner.ts تحويل المخطط إلى مشروع مدته 120 ثانية
src/engine/renderer/  renderFrame الحتمي (للمعاينة والتصدير معًا) والمشاهد
src/engine/audio/     توليد الموسيقى وتجهيز ملف الزائر الصوتي
src/engine/export/    فحص الترميزات، والتصدير عبر Mediabunny، والتحقق من الملف
src/app/              واجهة React العربية
docs/                 وثيقة المنتج، والبنية، وخطة الاختبار
```

راجع `THIRD_PARTY_LICENSES.md` لتراخيص المكتبات والخطوط والأيقونات.
