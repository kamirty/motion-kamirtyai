# خطة الاختبارات وشروط القبول

## البوابة صفر: إثبات 120 ثانية قبل بناء واجهة ضخمة
- [ ] مشروع من 3 مشاهد عربية يغطي 3600 إطارًا عند 30fps.
- [ ] إمكانية المعاينة والتنقل إلى أي إطار.
- [ ] صورة المعاينة عند إطار 300 تطابق صورة إطار 300 في التصدير بصريًا.
- [ ] فيديو MP4 مدته 120ث على Chrome/Edge Windows إن دعم الجهاز الترميز.
- [ ] فيديو WebM صالح في حالة عدم دعم MP4، مع رسائل مفهومة.
- [ ] تحقق برمجي/metadata من مدة الملف: خطأ لا يتجاوز إطارًا واحدًا (1/30 ثانية).
- [ ] حالات تقدم التصدير وإلغاء العملية، ولا واجهة عالقة أو نجاح وهمي.
- [ ] العربية متصلة وصحيحة ومحاذاة RTL وأمثلة عربية + 2026 + AI.
- [ ] منع اقتطاع العناوين الكبيرة وخروج النص من منطقة العرض.
- [ ] اختبار تباين الألوان وعدم تجاوز العناصر حواف الشاشة.
- [ ] تنظيف الذاكرة والمقاطع بعد الإلغاء أو الاكتمال.

## مصفوفة التوافق
**أولوية 1:** Windows 11 Chrome وEdge حديثان؛ 720p / 30fps؛ اختبار متصفح منخفض الذاكرة.
**أولوية 2:** Safari macOS وFirefox؛ feature detection لا افتراض مسبق.
**أولوية 3:** Android متوسط وiPhone؛ قد نخفض الدقة أو نعرض التعديل والمعاينة دون تصدير إذا لم تتوفر الإمكانيات.

## وظائف الواجهة
- [ ] وصف فارغ يسبب رسالة واضحة.
- [ ] نص عربي طويل يزيد الحد ويعرض تنبيهًا.
- [ ] مشروع محفوظ JSON ثم مستورد ينتج المشاهد والتوقيت ذاتهما.
- [ ] كل تغير في النص أو اللون ينعكس على المعاينة والتصدير.
- [ ] تغيير مقاس 16:9 / 9:16 / 1:1 يحافظ على الهوامش بلا قص للنص.
- [ ] 120 ثانية محفوظة بعد حذف أو إضافة مشهد وتوزيع المدد.
- [ ] لا طلب شبكي ينقل مدخلات الزوار أو المشاريع.

## سجل القياس لكل تجربة
- اسم المتصفح وإصداره ونظام التشغيل، حجم الذاكرة التقريبي إن توفر دون تتبع.
- codec المختار، الدقة، fps، الحجم النهائي، الزمن المستغرق، نجاح/فشل، رسالة الخطأ.
- تقارير يتم إنشاؤها محليًا بطلب المستخدم بدل جمعها تلقائيًا.

## معيار الإطلاق العام
10 مشاهد مختلفة، فيديو مدته 120ث، نص عربي مقروء، MP4 في البيئة الأساسية المدعومة، بديل واضح عند عدم الدعم، وصيانة الشيفرة باختبارات موثقة.
