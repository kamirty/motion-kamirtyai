# المهمة الأولى الجاهزة للإرسال إلى Claude Code

نحن نبني منصة Kamirty Motion، مولّد إنفوجرافيك متحرك مجاني للزوار، منفصل عن Blogger ويُربط به برابط مباشر. اقرأ ملفات README.md وCLAUDE.md وdocs/*.md وschemas/project.v1.schema.json.

**نفّذ Proof of Concept فقط، لا المشروع كاملًا:**
1. أنشئ React + TypeScript + Vite محليًا، واجهة عربية RTL بسيطة للمعاينة والتصدير.
2. عرّف مشروعًا ثابتًا يضم 3 مشاهد عربية بأنماط رسوم مختلفة، موزعة على 3600 إطار عند 30fps (120 ثانية)، بدقة 1280×720.
3. أنشئ `renderFrame(project, frameIndex, ctx)` حتميًا وقابلًا للاختبار، بحيث المعاينة والتصدير يستخدمانه نفسه. استعمل خطًا عربيًا محليًا وترتيب RTL سليمًا، لا تعكس النص العربي يدويًا.
4. نفّذ تصدير MP4 عبر Mediabunny/WebCodecs **فقط إذا كان الترميز مدعومًا**؛ وإلا جرّب WebM أو اعرض عدم الدعم بوضوح. اعرض تقدّمًا فعليًا وإلغاءً نظيفًا.
5. صدّر مشروع JSON، واختبر صحة مدته وتجميع الإطارات. امنع الحشو وإدراج خدمات مدفوعة.
6. اكتب اختبارات timing/schema، اختبر حالة unsupported codecs، واجعل build يعمل.

**قبل كتابة الشيفرة:** اعرض خطة قصيرة، قائمة ملفات، ومخاطر التصدير والذاكرة.
**بعد التنفيذ:** أرسل قائمة الملفات التي تغيّرت، أوامر الاختبار ونتائجها، رابط/صور المعاينة إن توفرت، ما الذي عمل فعلاً، وما الذي لم يكتمل. لا تدّعِ نجاح فيديو 120 ثانية قبل تشغيله والتحقق من ملف الناتج.
**تمنع في هذه المهمة:** حسابات، قاعدة بيانات، أي API مدفوع، صوت آلي، محتوى سحابي، نشر DNS، تعديلات على جاوب أو بلوجر، تصميم ثلاثي الأبعاد.
